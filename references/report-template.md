# 报告结构与学习模块

以下是完整资料下的报告组织方式。按书的实际结构调整层次与篇幅；保持问题导航、全书框架、逐章覆盖和四问的作用。资料不足时按照 `source-workflow.md` 缩减，不能保留空架子冒充完成分析。

## 控制重复与短材料篇幅

完整性指覆盖应读内容并完成不同学习任务，不要求把一个观点反复展开。同一论证主要在对应章节解释一次；难点补充定义或辨析，全书综合提炼跨章关系，卡片保留可复用判断。后面的模块已有内容时简短回指，只有新信息才展开。

对于正文仅少量段落、各章很短的完整材料：保留每章四问，但每问可用一两句完成；将难点就地嵌入相关章节，用紧凑的全书四问收束；减少自测与卡片数量。可以合并小节或用表格承担多个功能，不按长书模板把短材料扩展成反复讲同一结论的长报告。长书仍须覆盖全部可得章节，不用压缩规则省略实质内容。

## 1. 简明总览与阅读问题

开头交代：书名、作者、已核实版本、资料覆盖状态，以及一句话主张。给出读者最需要了解的核心收获与限制，随后列 3—5 个由资料支持的关键问题。

问题应具体到能被回答，例如“作者如何解释某种现象”“这个方法需要哪些条件”；不能全部写成“如何成功”。可以标记 Q1、Q2 等，在章节和全书综合中回收。不要把分析者设定的问题冒称为作者原话。

## 2. 全书框架与关系图

讲清作者面对的问题、必要背景、核心主张、各部分功能和论证推进。背景不是每本书都要写成“旧理论失败后作者破局”；仅在来源支持时这样解释。

将章节组织成一张可浏览的地图或表：

| 实际章节 / 部分 | 核心问题 | 在全书中的作用 | 与前后文的具体关系 |
|---|---|---|---|

以实际证据支持的概念图、流程图或时间线补充。Markdown 可用简洁 Mermaid；环境不能显示时同时提供一小段文字说明。图是结构导航，不代替论证。

- 节点用准确概念或实际章节，连线标明“定义”“支持”“限制”“应用”等关系。
- “属于”“先讲”“相关”不等于“导致”；不要给叙述先后关系画因果箭头。
- 重要关系应能读成完整判断，并在正文中找到依据。
- 分清书本的实际目录结构和分析者重组的解释模型。

## 3. 逐章四问与章节关联

每章至少回答以下不同问题，可以用紧凑小标题，避免一章机械分出大量重复栏目。

### 本章问题与位置

说明本章解决的问题、承担的功能以及与全书关键问题的联系。

### 听：作者讲了什么

准确概括本章主张、概念、论证与代表案例；重要内容交代“为什么这样判断”，不能只有口号。原书没有案例时不补造原书案例；自拟例子移到解释或应用并标注。

### 想：与什么相联系

解释与已读其他章节、外部理论或具体经验的联系。不能仅列“系统思维、心理学、某作者”等标签；说明对应概念、共同点、差异及联系的理由。外部比较较长时引用后文的集中比较，避免各章重复。

### 变：可以形成什么认识

提出供读者检验的认知提炼，可以采用：

> 一种常见理解 → 本章能够支持的修正 → 成立条件 / 尚未解决之处。

也可形成“遇到什么情境，应先判断什么”的规则。没有读者反馈时，只能写“可供检验的认识”“可能修正的判断”，不能捏造其读前观念或实际变化。

### 用：可以怎样应用

选择合适的场景，交代：触发情境、需要的信息、第一步行动、观察什么、何时调整。理论、历史章节可给出解释与判断练习，不强行安排商业实验。

个人业务案例只在背景相关时增加，并区分真实数据与假设。为便于理解构造的数字必须标为示意，不能包装成经营诊断。

### 本章与其他章节的关系

指出具体联系，例如“本章定义了后文使用的某个概念”“后文给前述主张增加了适用条件”。必须同时说明两端的内容；仅有一端正文时，只描述已知关系或明确暂不能确认。

## 4. 难点解释与跨章整合

### 白话解释与复述练习

选取全书真正困难的 3—5 个概念或更少，可以放在相关章节就地解释，不必集中重复一遍。推荐形态：

1. 准确定义与无背景读者能理解的解释。
2. 一个具体例子，以及例子如何体现该概念。
3. 一个反例或易混概念，说明差别。
4. 如果使用类比，说明类比在哪些地方失效。
5. 一道供读者自己解释或判断新情境的题。

费曼式练习的关键是读者自己解释、发现卡点、回查并再解释。模型提供解释示范只是准备材料，不能据此宣称读者已完成费曼学习或掌握知识。

### 全书重新串联

回收开头的问题，说明各章怎样共同支撑、修改或限制全书主张；串联反复出现的概念及其变化。明确存在的张力与未解问题，不为了“完整闭合”编造一致性。

## 5. 外部知识联结、批判与边界

默认对约 3—5 个有价值且可核实的关联深入比较；证据不足时减少。优先围绕共同问题，使用同一组比较维度：

| 共同问题 | 本书的回答与依据 | 对照观点与来源 | 共同点 / 实质分歧 | 条件与应用差异 |
|---|---|---|---|---|

分清直接概念联系、互补解释、冲突、不同分析层级和启发性类比。不要挂一串书名，也不要把对照作者所有著作概括成一个未经核实的口号。

批判聚焦重要观点：论据是否足够、是否从相关跳到因果、个案能否推广、是否遗漏条件、何种反例会迫使判断改变。区分作者当时的知识范围、译版差异和后来的证据；提出反对意见也需依据。

## 6. 全书级听、想、变、用及行动方案

- **听**：综合整本书最值得保留的思想，不重复各章摘要。
- **想**：说明本书在相关知识中的位置及最重要的连接。
- **变**：提炼少量带条件的判断原则，注明仍需验证之处。
- **用**：将分散方法组合成有顺序的行动或判断方案。

应用方案先通用，相关背景充分时再贴近个人场景。需要验证时写清问题、所需数据、最小可行行动、主要观察指标与调整条件。没有可操作的实验时，使用情境分析、决策清单或解释练习，不编造实验结果。

## 7. 理解自测与参考答案

默认全书 5—8 道自测题；短材料按内容减少，不为凑题重复考定义。适当包含复述、解释论证、比较概念、识别边界和新场景迁移。

先完整列题，随后放置独立的“参考答案与回查位置”小节。可用 Markdown 分隔或可折叠区；不依赖特定阅读器才能作答。

- 题目只能依赖已分析材料或题干给出的信息；不能考缺失章节。
- 作者观点有可回查定位；分析题说明判断依据与可能答案，不把开放题伪装成唯一答案。
- 应用题给出分析标准和必要假设，避免假设用户实际数据。
- 提供一段可调整的间隔练习起点：读完先不看答案回忆主线；约 2—3 天后重做薄弱题并解释难点；约一周后混合练习复述、边界和新情境题。每次先作答再回查，仍依赖答案或遗漏条件时缩短间隔，能独立解释且正确迁移时再拉长。根据材料与读者表现调整，不宣称这些间隔经过针对本书的最优验证。
- 默认只交付题目与答案，不打断报告等待逐题作答，不自动创建提醒。用户选择互动或提交答案时，再逐题追问、定位误解并提出针对性补练。
- 即使某题回答正确，也只反馈该题表现；不据此断言全书已掌握或预测长期记忆效果。

## 8. 可复用知识卡片

默认在附录提供约 5 张最有价值的卡片；资料很短时减少，用户要求精简时可省略。卡片从已核实内容提炼，可以离开章节独立阅读。每张包含：

- 一个明确的主张或判断问题。
- 用自己的话解释，以及必要的论据 / 例子。
- 适用条件、边界或可能反例。
- 来源：书中位置或外部直接链接；分析者提炼须标明。
- 与本报告其他卡片或已有知识的关系及理由，如支持、补充、限制、反驳或类比。

这些字段是本 Skill 的输出设计，不冒称为某位作者规定的唯一卡片格式。不要杜撰读者已有的卡片、笔记 ID 或知识库；没有真实关联时不强加链接。默认附在同一报告中，不自动创建一堆独立文件或数据库。

## 9. 来源与章节覆盖

整理实际使用的资料及直接链接；本地来源写明文件、章名及必要定位。列出逐章资料覆盖、无法确认的内容和完成深入分析所缺的材料。引用标记应能对应回来源，避免堆一份未实际阅读的书单。

## 方法依据与使用边界

以下链接解释借鉴的思路，属于 Skill 设计参考，不能代替具体书籍的内容证据。报告无需每次复制这一组链接；说明采用的方法时可按需要引用。

- **SQ3R / 问题导航与复述**：[康奈尔学习策略中心](https://lsc.cornell.edu/how-to-study/reading-strategies/textbook-reading-systems/)。借鉴提问与回忆，不把生成报告等同于读者已经完成流程。
- **费曼式解释 / 讲授与补缺**：[Caltech 教学学习中心](https://ctlo.caltech.edu/aboutctlo/whoweserve/undergraduates/learning-resources/learning/power-of-teaching)。采用解释、发现卡点和回查，不宣称网上流行的固定步骤是费曼本人发表的唯一算法。
- **概念图与关系词**：[IHMC / Alberto J. Cañas](https://cmap.ihmc.us/docs/Proposition.php)。连线构成有意义的判断，不将一切关系画成因果。
- **连接笔记**：[Sönke Ahrens 作者网站](https://www.soenkeahrens.de/en/takesmartnotes)。借鉴可复用与关联的思路，不把字段数或卡片数量说成原方法硬规定。
- **主动回忆与间隔练习**：[学习科学研究者综述](https://www.learningscientists.org/blog/2016/8/18-1)、[Roediger 与 Karpicke 的文章材料实验](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/)。研究支持相关练习，不等于本报告格式已得到实验验证，也不保证个人学习结果。
- **参考项目**：[tsrenzhi/book-knowledge-card](https://github.com/tsrenzhi/book-knowledge-card)。借鉴先定位问题、讲清机制与案例、结构化比较的设计；本 Skill 的深度报告结构与文字独立编写，未复制其模板、字体或代码。
